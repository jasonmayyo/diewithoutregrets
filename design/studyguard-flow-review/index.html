04 / A practical device test

Use the latest local iOS build with the deployed Worker. Deployment updates the backend; it does not install the app changes on your phone. Start with a few representative sources and record concrete examples of anything that fails.

1. Generate from real material

  • Try short class notes, a longer PDF with several sections, and non-English notes if you use them.
  • Keep the source open beside the resulting deck. Check that the saved count matches the cards you received.
  • Sample 10–15 cards per deck, including content from the beginning, middle and end. Look for missing major topics and repeated cards.
  • Try one failed or cancelled request. Your input should stay available after an error; cancelling should not save a deck later.

2. Check each sampled card

  • Is the answer supported by a specific passage or page?
  • Is the question clear without needing the surrounding paragraph?
  • For multiple choice, is exactly one option correct and are the wrong options plausible?
  • Does the explanation match both the source and the answer?
  • Flag wrong facts, ambiguous answers, vague prompts, duplicates and skipped sections separately.

3. Study and ask follow-ups

  • Answer one card correctly and one incorrectly. Check the correction, next question and final time earned.
  • Tap Ask about this card, then try “Why?”, “Give me an example” and “I think this is wrong”. Check that replies address that card and the previous follow-up.
  • A follow-up must not count as a graded answer or earn time. Answer card should return you to the study question.
  • Try offline chat, closing while a reply is pending, and reopening. Check the saved explanation and watch for stray late messages.
  • Choose each monster in turn, open a blocked app, and check its image, monster name and actual app name on the shield. Test both a cold and warm app launch; the button should land straight in that monster’s chat.
  • Finish a round and confirm the selected apps really unlock. Check that every correct answer triggers its own hourglass flight and increases Time earned. Wrong answers and follow-ups must leave it unchanged; the final balance must match the awarded minutes. Try Reduced Motion and leaving during the animation; earned time must still be available. Check the keyboard and switching between all four monsters.
When something is wrong: save a screenshot, the source title and page/passage, what you expected, and what happened. A wrong answer or multiple valid options should be fixed before release. Passing this small sample is useful evidence, but does not prove every generated card is accurate.
