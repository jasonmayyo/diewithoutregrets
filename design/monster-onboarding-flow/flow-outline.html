What changes + fallback paths

Show the product first. Welcome recording and two animated explanations lead into personalization, gender, age, screen time, the annual projection and the monster picker. Keep the name question inside the first conversation.

Move useful questions into chat. Ask only unanswered questions: name, study level, first module or topic, and optional test / exam date. Gender, age and phone time are already saved. The module question sets the first deck’s focus; it does not ask for the whole degree.

Keep the conversation easy. One question per message, quick replies where possible, editable answers and visible progress. The monster adds personality; the setup follows a clear sequence. Users can type too.

Keep identity explicit. Gender includes “Prefer not to say.” Use their name unless they have set a pronoun preference in Profile. Never infer pronouns from gender.

Keep the plan simple. Use one minute per correct card by default. Practice leads straight to the plan, with no rate-selection question.

Keep moving. Upload fails → retry or use a sample. Wrong answer → kind correction and retry. Permission denied / no apps chosen → return to setup later; no unlock claim.

Keep continuity. Save the name, preferred forms of address, monster, study context, deck, rule and setup position. Cancelled purchase → offer; restore → resume. Incomplete setup gets one next action on Home.

Keep the joke in character. The greeting and examples above change with the monster. Guarantee one curated opening meme in onboarding; ordinary chats keep their existing reaction cadence.

Keep the first win honest. The pre-purchase card is practice. Start earning only in the real round after setup; never count the practice answer twice. Sample users can add their own notes afterward.
